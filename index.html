Neo Personal Cals

Personal productivity tools by Neo Hung

Neo Personal Cals is a set of personal, non-commercial tools used only by its developer. With the user's consent it reads the user's own Google Calendar (read-only) and Gmail on the user's own computer, for example to send the user a daily summary of today's calendar events.

Neo Personal Cals 是開發者自用的個人工具（非商業用途）。經使用者同意後，在使用者自己的電腦上讀取其 Google 行事曆（唯讀）與 Gmail，例如每天早上把當天行程整理後傳給使用者本人。

The app is not offered to the public, and Google user data is not shared with anyone. 本工具不對外提供，也不會與任何人分享 Google 使用者資料。
