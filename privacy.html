Privacy Policy

Neo Personal Cals · Last updated: 2026-10-22

1. Who we are

Neo Personal Cals is a personal, non-commercial tool developed and used by Neo Hung. It is not offered to the public.

2. Data we access

  • Google Calendar (read-only): calendar list and event details (title, time, location, meeting link) of the signed-in user.
  • Gmail: messages of the signed-in user, only when the user asks the tool to read, search, or send email.

3. How data is used

Data is used only to provide features to the same user, for example sending the user a daily summary of their own calendar events through the user's company-internal end-to-end encrypted messenger. Data is not used for advertising, profiling, or any other purpose.

4. Storage and sharing

  • The tool runs on the user's own computer. OAuth tokens are stored locally and encrypted with Windows DPAPI.
  • Calendar and email content is not stored on any server operated by the developer and is not sold, transferred, or shared with third parties.
  • The user can revoke access at any time at https://myaccount.google.com/permissions.

5. Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
